---
name: RanchTrack auth pattern
description: Session management approach and the custom-fetch credential patch required for cookie-based auth.
---

Sessions are stored in an in-memory `Map` in `artifacts/api-server/src/lib/sessions.ts`. Passwords are hashed with `crypto.createHash('sha256').update(pw + "ranchtrack_salt_2024")`. No bcrypt dependency.

`lib/api-client-react/src/custom-fetch.ts` has `credentials: "include"` added to every fetch call so the browser sends the session cookie automatically.

**Why:** The Orval scaffold ships `custom-fetch.ts` without `credentials: "include"`. Without this patch, all authenticated API calls return 401 in the browser even after login.

**How to apply:** If `custom-fetch.ts` is ever regenerated by Orval, re-add `credentials: "include"` to the `fetch(input, { ... })` call in `customFetch`.
